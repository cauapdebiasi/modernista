Três paletas, sorteadas a cada abertura

Cada paleta define só as cores-base. Todo o resto (primária, perigo, sombras, rampa das barras) deriva delas, então trocar data-palette no <html> repinta tudo. O script de início sorteia uma e nunca repete a anterior.

Botões que afundam a sombra

Ao apertar, o botão desce 3px e a sombra some, como uma tecla. Os fantasmas e links só encolhem um pouco.

Números que rolam, barras que enchem

Cada dígito gira como um odômetro e todos param juntos em 3s, na curva cubic-bezier(0.16, 1, 0.3, 1). As barras enchem no mesmo tempo. Valor negativo rola pra baixo, com a escadinha do som descendo.

Sons do app

Diálogos que entram e saem

Todos têm animação de saída: o componente fica montado por 260ms com a classe .closing (hook usePresence). O seletor de meses desliza o ano pro lado da seta.

Sons sintetizados

Nada de arquivo de áudio: tudo é Web Audio. Um som por ação, mais a escadinha pentatônica da contagem. Todo botão faz o "gota" de clique.

Modernista é extraído do Planejador Financeiro. Os componentes React estão em src/; esta página usa o mesmo CSS com um pouco de JavaScript puro pra animar.
